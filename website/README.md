# Voice & Audio Recorder — Website

Static marketing site for the Fenwick Labs Chrome extension.

## Stack

- Static HTML / CSS
- Vercel-ready via `vercel.json`

## Local preview

```bash
cd website
python -m http.server 4177
```

Open `http://127.0.0.1:4177`.

## Deploy on Vercel

1. Import `Mangesh347/Voice-Audio-Recorder`.
2. Set **Root Directory** to `website`.
3. Framework Preset: Other.
4. Deploy.

## Pricing on this site

- Free: 10 recordings / calendar month
